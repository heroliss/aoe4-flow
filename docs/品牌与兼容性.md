# AoE4 Flow · 帝国时代 4 自动化助手

**AoE4** 明确《帝国时代4》的主要使用场景，**Flow** 表达节点式流程编排。中文名“帝国时代 4 自动化助手”直接说明用途。原名 AOE4 Flow Editor／AoE4 自动生产助手；源于自动出农，逐步覆盖商人、渔船等生产，以及可组合的图像识别与输入操作。

引擎支持通用截屏、模板匹配、OCR、判断、按键和点击节点；AoE4 的建筑计数、资源预算与生产逻辑仍属于专用节点和内置流程。其他界面需要自行配置识别区域、模板、条件与操作。

## 更新已有安装

- 下载正式版压缩包，解压后运行 `AoE4-Flow.exe`。用户流程、模板和经典工具的 `shortcuts.json`／`config_override.json` 保持原格式；请保留这些文件。
- 偏好设置改存 `%APPDATA%\AoE4Flow\settings.json`。新位置尚无设置时读取 `%APPDATA%\AOE4AutoVillager\settings.json`，首次保存写入新位置，旧文件保留。
- `.flow.json`、节点类型、JSON 参数键、内置流程文件名保持兼容，无需转换。
- 调试变量采用 `AOE4_FLOW_EDITOR_DEBUG`／`AOE4_FLOW_NO_ELEVATE`，旧变量继续有效；新变量优先。
- 仓库地址为 [heroliss/aoe4-flow](https://github.com/heroliss/aoe4-flow)。旧 GitHub 仓库地址保留重定向；既有版本与资产仍在 Release 中。

默认启动仍会请求输入屏蔽所需的管理员权限。只编辑或查看流程可执行 `AoE4-Flow.exe --no-elevate`，以普通权限使用；此时输入屏蔽不可用。编辑器启动不会自动运行流程。
